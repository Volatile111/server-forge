Add mods

Downloads there install automatically. A newer version of a mod you already have replaces it (the old one is backed up).

Installed

Turning a mod off moves it to BepInEx\disabled_mods, outside the folder BepInEx loads from. Removing a mod moves it to BepInEx\achilles_backups - nothing is ever deleted.

Ships

One file per ship in the game (written by the "We Mod Any Ship" plugin). Turn a ship's file off to use the game's own stats for it, or press Stats to change them. Changes apply the next time Star Valor starts.

Update your mods

Checks every plugin against GitHub and Nexus, installs every safe update automatically, and backs up the old versions.

Press Update all (or Check only) to look for new versions.

Versions for Star Valor

Profiles

A profile is a saved set of mods. Applying one turns on exactly those mods and turns everything else off. Vanilla always means zero mods.

Save slots

Whichever profile is linked to a slot is what gets applied when you launch into it. Slots played before this tool existed show as Unknown until you tag them once.

Nexus Mods

A free personal API key lets the updater recognise mods that came from Nexus and check them for new versions. Get yours at the bottom of nexusmods.com → Site preferences → API Keys.
